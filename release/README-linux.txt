ALLEY CAT for Linux x86-64
==========================

A native Linux version of Alley Cat (Bill Williams / SynSoft, IBM, 1984),
rewritten in C. The original game's data is not included.

You need your own original CAT.EXE (55,067 bytes, dated 22 August 1984).
Put it next to alleycat, or run ./alleycat /path/to/CAT.EXE. The file is
only read, never changed. A graphical Linux desktop and SDL2's usual runtime
dependencies for video and audio are required.

CONTROLS
  Arrow keys          move / climb / jump
  Alt                 special action
  Esc                 pause
  Ctrl-S              sound on / off
  Ctrl-R              restart
  Ctrl-M              return to menu
  F11 or Alt+Enter    full screen
  F12                 screenshot
  Game controller     PC joystick, D-pad / A / Start for arrows / Alt / Esc
